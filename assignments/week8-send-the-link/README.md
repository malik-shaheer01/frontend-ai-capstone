# Capstone — Send the Link: Launch, Demo & Story

A portfolio that never gets a second project goes stale. This is the habit setup for adding the next
one, written down now while everything is still fresh.

## How to add the next case study

1. Copy the three-beat shape already used in [`assignments/week1-ai-workflow-drill/WORKFLOW.md`](../week1-ai-workflow-drill/WORKFLOW.md):
   **Problem → What you did → What came of it.** That file is the template — reread it before writing
   the next one instead of starting from a blank page.
2. New case studies live as one `WORKFLOW.md`-style write-up per project, either alongside that
   project's own `assignments/<week>-<slug>/` folder (same pattern as every assignment in this repo)
   or, once the Shopify capstone site exists, as its own page/section on the live site.
3. Link the new write-up from [PROGRESS.md](../../PROGRESS.md) and the main [README.md](../../README.md)
   the same way FE-02's WORKFLOW.md is linked today, so it's discoverable from the repo's front door,
   not buried in a folder.
