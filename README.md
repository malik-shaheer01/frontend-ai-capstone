# frontend-ai-capstone

Front-end AI Engineering track repo for the FlyRank AI Internship, by Shaheer Nawaz.

This repo tracks weekly build work culminating in a capstone: a responsive, Tailwind-built site, deployed and linked publicly below.

## What's here

- Weekly assignment work for the **Front-end AI Engineering** track
- The track capstone: a responsive, Tailwind-built site

**Live capstone:** _not deployed yet — link will go here once the capstone ships_

## Getting started

Requires Node.js LTS and Git. Clone the repo, then check each `assignments/<week>-<slug>/` folder for its own run instructions:

```bash
git clone https://github.com/malik-shaheer01/frontend-ai-capstone.git
cd frontend-ai-capstone
```
